# Malawi ESBL-producing *E. coli* genomics

## Data and code repository for study on inter-household networks of gut colonising ESBL-producing *E. coli* in rural Malawi

The data required to run the [analysis](https://amoreo71.github.io/malawi_esbl_e_coli_genomics/Code/Malawi_ESBL_V3.html) in R can be found within the 'Data' folder.

**Whole-genome sequencing reveals inter-household networks of gut-colonising ESBL-producing Escherichia coli in two rural Malawian districts**
